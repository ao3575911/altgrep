## Purpose

How AltGrep acquires its first 20 sellers and first 100 searchers without a social feed.

## Facts

- Category is not “marketplace.” Category is “unusual listings with a named vouch trail.”
- CLI-native story is real only if the CLI ships on day one.
- Seed inventory only: handle (control-proven), consulting, dossier. Full taxonomy in `04` is not a launch queue.
- No GitHub push unless Adam explicitly orders that gate.

## Thesis

Thesis. Marketing is a search box and a category manifesto, not a growth-hack loop.

### Positioning line

Grep the listings that do not belong on eBay.

### Audience

- Operators selling names, briefs, methods, office hours.
- Buyers hunting rights, handles, or a specialist for one job.
- Small private groups running a deal room.

### Channels (v1)

1. CLI install README and a single man-page tone site.
2. X for the CLI story; GitHub only if Adam orders a push/public repo gate.
3. Direct invite to 20 known operators.
4. One essay: “You cannot sell a raw idea. Here is what you can list.”
5. No paid ads until prohibited-list and notice channel exist.

### Forbidden rhetoric

- “The next eBay.” / AltBay / bare Alt / Altered as this product.
- “Guaranteed unique ideas.” / earnings promises on dossiers.
- “Untraceable.” / E2E claims without crypto in repo.
- “We replace government ID.” / KYC / myID / AGDIS.
- UI “verified” as a stand-in for control-proven handle.
- Coffee puns if any coffnup-adjacent brand leaks in. This product is not that brand.

### Metrics

- Listings that survive 7-day moderation.
- Inquiries that get a reply.
- Vouches given after a completed introduction.
- CLI weekly actives among sellers.

No follower vanity. No invented user counts in public copy.

## Actions

1. Write the manifesto page before the landing page hero.
2. Ship `altgrep search` as the demo, not a video ad.
3. Counsel gate before any paid-tier or offer copy that touches ACL.

- Whether a public changelog is the only blog.
